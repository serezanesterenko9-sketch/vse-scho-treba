# Все що треба

Вебзастосунок-дошка оголошень для публікації, пошуку та модерації пропозицій у своєму місті.

## Проблема, мета, аудиторія
- **Проблема:** оголошення розкидані по месенджерах і соцмережах, важко шукати, багато шахрайства й застарілих публікацій.
- **Мета:** єдиний зручний сервіс із пошуком за категоріями та модерацією.
- **Аудиторія:** мешканці міст 18–55 років, студенти, малий бізнес, приватні продавці.

## Ролі
- **Гість** — перегляд і пошук оголошень, реєстрація та вхід.
- **Користувач** — керування власними оголошеннями й профілем, обране, скарги.
- **Модератор** — опрацювання скарг, приховування оголошень.
- **Адміністратор** — керування користувачами, ролями, категоріями.

## Основні функції
Реєстрація та вхід, створення й редагування оголошень, каталог із пошуком і фільтрами, обране, скарги, модерація, адміністрування.

## Сторінки
Головна, Каталог, Сторінка оголошення, Вхід і реєстрація, Особистий кабінет, Створення/редагування оголошення, Панель модератора, Панель адміністратора, Сторінки помилок.
